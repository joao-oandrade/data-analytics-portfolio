
# E-commerce Growth Analytics

## 1. Project Overview

This project aims to analyze real Brazilian e-commerce data to identify business opportunities related to revenue growth, customer retention, customer experience, and operational efficiency.

The analysis will focus on transforming raw data into actionable insights using SQL, Google BigQuery, Python, statistics, and data visualization.

## 2. Business Problem

How can an e-commerce business improve revenue, customer retention, and operational performance using data?

## 3. Objectives

- Analyze sales performance and revenue trends.
- Understand customer purchasing behavior.
- Investigate customer retention and repeat purchases.
- Identify high-value customer segments.
- Analyze delivery performance and customer satisfaction.
- Identify business opportunities through statistical analysis.

## 4. Dataset

Source: Olist Brazilian E-Commerce Dataset

Dataset link: https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

The dataset contains information about orders, customers, products, sellers, payments, deliveries, and customer reviews.
